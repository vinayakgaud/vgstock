# VGStock

A one-stop trading workspace: live market data, multi-broker execution,
portfolio tracking, AI-driven signals, and backtesting.

**Stack (polyglot, chosen step by step):**

| Layer     | Tech        |
| --------- | ----------- |
| Backend   | Go          |
| Frontend  | Next.js     |
| ML        | to be decided later |
