# Contributing to VGStock

This is a personal learning project. Before contributing:

1. Open an issue or discussion describing what you want to change.
2. Wait for a go-ahead before starting work.
3. Follow existing code conventions; match the style of neighboring files.
4. Run the project's verification tasks (see README / Taskfile) before submitting.

Don't commit real secrets or `.env` files. Use `.env.example` and a secrets manager.
